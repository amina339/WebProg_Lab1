# Магазин игрушек Mina

Учебный проект — интернет-магазин игрушек на чистом HTML, CSS и JavaScript.
Без фреймворков и библиотек.

## Что умеет

- Показывает каталог игрушек
- Добавляет товары в корзину
- Меняет количество и удаляет товары
- Считает итоговую сумму
- Сохраняет корзину в localStorage (не пропадает при обновлении)
- Оформляет заказ через форму
- Адаптивный дизайн (ноутбук, планшет, телефон)

## Технологии

- HTML5
- CSS3 (Grid, Flexbox, медиазапросы)
- JavaScript (чистый, без фреймворков)
- localStorage
